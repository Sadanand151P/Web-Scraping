# CodeAlpha Task 1 — Social Media Campaign Design

## Objective

Create a 7-day social media content calendar for CodeAlpha's Instagram and LinkedIn pages.

## Features

* 7-day content calendar
* Instagram and LinkedIn posts
* Post ideas
* Captions
* Relevant hashtags
* Platform filtering
* Responsive web design

## Technologies

* HTML
* CSS
* JavaScript

## Files

```text
index.html
style.css
script.js
README.md
```

## How to Run

Open `index.html` in any web browser.

## Outcome

The project provides a simple and attractive 7-day social media campaign to improve CodeAlpha's brand visibility and audience engagement.
